MyCineList

A full-stack movie application with Google sign-in, ratings, and personal watchlists.

A personal movie collection

MyCineList lets users search for movies, rate them, and keep personalized watchlists. The interface brings discovery and personal organization into the same application.

Identity and persistence

Google OAuth authenticates users. The Node.js and Express backend connects application requests with MongoDB, where user data is stored.

External movie data

The MovieDB API supplies movie information, while MongoDB holds the application’s user data. The backend is the connection between these sources and the frontend.
