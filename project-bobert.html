Bobert’s Mad Dash to the Silly and Whimsy Factory

A 3D skateboarding game built by a team of 14 for the Gameplay First game jam.

My contribution

I implemented a combo input system that maps input sequences to trick animations. A tree-like structure organizes the sequences and the tricks they can trigger.

Timing matters

Animation timing and input buffering determine when a new trick can start. The system accepts valid inputs during the appropriate windows rather than triggering every input immediately.

Connecting input and animation

The central implementation challenge is coordinating a sequence of player inputs with the animation currently in progress. The combo structure, timing windows, and buffering work together to control the transition to the next trick.
