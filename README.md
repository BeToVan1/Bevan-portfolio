## Featured Projects

### ICS Search Engine

A search engine built to index and retrieve information from more than 50,000 UCI web pages.

**Highlights:**
- Built an inverted index for efficient document retrieval
- Implemented TF-IDF scoring and tiered indexing
- Handled malformed HTML and duplicate content
- Achieved query response times under 300ms
- Built a Flask-based web interface for displaying results

### StockPredictor

A full-stack application that uses machine learning to predict stock prices from historical market data.

**Highlights:**
- Developed LSTM models using TensorFlow
- Built a NestJS backend with REST APIs
- Processed historical financial data for model inference
- Integrated the Finnhub API for financial news
- Connected the ML pipeline with a web application

### MyCineList

A full-stack movie tracking application that allows users to search for movies, rate them, and maintain personalized watchlists.

**Highlights:**
- Implemented Google OAuth authentication
- Built backend functionality with Node.js and Express
- Used MongoDB for persistent user data
- Integrated the TMDB API for movie information
- Developed rating, search, and watchlist functionality
