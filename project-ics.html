ICS Search Engine

A search engine for more than 50,000 UC Irvine web pages, built around an inverted index and relevance ranking.

From pages to an index

The crawler feeds an HTML parser before documents enter the index. Handling broken HTML and detecting duplicate content keeps repeated or malformed pages from undermining retrieval.

Finding relevant results

An inverted index connects terms to documents. TF-IDF scoring weighs the terms for relevance, while tiered indexing organizes retrieval. The query engine returns complex query results in under 300 milliseconds.

Connecting the system

A Flask interface presents results from the query engine. The architecture connects crawling, parsing, indexing, ranking, and a browser-facing results view.
