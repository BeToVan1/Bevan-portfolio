Codebase Archaeologist

A hackathon project that turns an unfamiliar Python repository into an explorable map of its structure, relationships, and evidence.

Try the live demo ↗View on GitHub ↗

Python / React / TypeScript / React Flow / Cloudflare Workers AI

From repository to evidence

Enter a public Python GitHub repository to explore its dependency map. Deep analysis extracts files, classes, functions, methods, and relationships with source locations. Hosted analysis pins the repository to a commit, keeping the evidence tied to the exact code that was analyzed.

Understand the structure

The explorer connects a React Flow map with source inspection, architectural patterns, structural risk findings, and supported execution flows. FastAPI routes and SQLAlchemy persistence form the initial framework-aware slice. Unresolved calls and incomplete paths remain visible rather than being presented as certain runtime behavior.

AI grounded in selected code

Optional Cloudflare Workers AI explanations interpret a selected symbol using retained source evidence. The system checks returned references against that evidence and keeps static facts, heuristics, and AI interpretations distinct. Citations support inspection; they do not guarantee that an explanation is correct.

How the pieces fit

  1. Public repository → pinned source. Analysis captures a specific commit and parses Python code without executing the repository.
  2. Static analysis → evidence graph. Symbols, dependencies, findings, and supported paths carry source references.
  3. Evidence graph → interactive explorer. The browser links map selections to relevant source and findings, with JSON report export/import.
  4. Selected symbol → optional AI interpretation. A server-held report reference retrieves the evidence for a cited explanation.

Scope of the hackathon beta

Python-first, with separate inventory and deep-analysis modes. Static analysis exposes useful structure but does not prove runtime execution, and test-proximity signals are not coverage measurements. Imported JSON reports are labeled unverified and cannot request AI explanations.
