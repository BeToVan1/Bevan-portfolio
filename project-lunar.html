Lunar Umbra

A 2D roguelike top-down tower defense game built by a team of 18 for Magical Girl Game Jam #12.

My contribution

I led the programming team and implemented card-based unit placement, enemy wave spawning, and battle phase management. These systems connect player choices to the progression of each encounter.

Data-driven content

The architecture uses Unity Scriptable Objects for cards, spells, companions, and units. Defining this content as data supports a scalable structure for the game’s different entities.

From placement to battle

Card-based placement establishes units, wave spawning introduces enemies, and battle phase management coordinates progression. The playable game brings these systems together under game jam constraints.
