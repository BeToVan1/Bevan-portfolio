StockPredictor

A full-stack application connecting machine learning predictions with market data and financial news.

The prediction pipeline

LSTM models built with TensorFlow use historical market data to predict stock prices. The application connects model inference to a web interface rather than leaving the model as an isolated experiment.

The API layer

The NestJS backend exposes REST APIs for predictions, user input, and real-time data. A React frontend calls that backend, which coordinates the model and external data sources.

Adding context

Finnhub integration brings relevant financial news alongside predictions. The backend returns the combined results to the frontend.
